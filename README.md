# ShahMat&I — сайт приложения

Сайт шахматного тренажёра «ШахМаты» (ShahMat&I).

- Сайт: https://takomak2012-cyber.github.io/ShahMatI-site/
- Приложение в RuStore: https://www.rustore.ru/catalog/app/com.windak.shahmati
- Политика конфиденциальности: https://takomak2012-cyber.github.io/ShahMatI-site/#privacy

## Структура

```
index.html      одностраничный сайт приложения
app-ads.txt     файл для рекламной сети Яндекса (РСЯ)
```

Сайт статический, публикуется через GitHub Pages из корня ветки `main`.

## Как обновить

1. Изменить файлы в этом репозитории.
2. Закоммитить и запушить в `main`.
3. GitHub Pages опубликует изменения автоматически.
