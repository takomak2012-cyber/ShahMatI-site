# ШахМатИя — сайт приложения

Сайт шахматного тренажёра «ШахМатИя» (ShahMat&I).

- Сайт: https://takomak2012-cyber.github.io/ShahMatI-site/
- Приложение в RuStore: https://www.rustore.ru/catalog/app/com.shahmat.game
- Пакет приложения: `com.shahmat.game`

## Структура

```
index.html      одностраничный сайт приложения
app-ads.txt     файл для рекламной сети Яндекса (РСЯ)
ads.txt         файл для рекламной сети Яндекса (РСЯ)
```

Сайт статический, публикуется через GitHub Pages из корня ветки `main`.

## Файлы для рекламной сети Яндекса (РСЯ)

`app-ads.txt` и `ads.txt` публикуются как есть, без правок, в корне сайта.
Проверка: https://takomak2012-cyber.github.io/ShahMatI-site/app-ads.txt

## Как обновить

1. Изменить файлы в этом репозитории.
2. Закоммитить и запушить в `main`.
3. GitHub Pages опубликует изменения автоматически.
